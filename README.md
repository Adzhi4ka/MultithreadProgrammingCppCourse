# Хранилище файлов

* REST API  
для общения между клиентом и сервером

## Файл (сущность)

* Обладает состоянием: читается, модифицируется. Модифицироваться может максимум одним, читаться многими
* Метаданные, когда и кем изменили
* Обладает уровнем доступа: недоступен, можно читать, можно модифицировать 

## Пользователь (сущность)

* Обладает набором файлов
* Обладает определенным уровнем доступа
* Может читать файлы
* Может модифицировать их

## Клиент (функционально)
* Может запросить файл на чтение или модификацию
* После модификации отправляет на сохранение

## Сервер
* Хранит файлы и их метаданные
* Мониторит состояние файлов
* В случае запроса на модификацию (может лучше сделать после самого факта изменения), отправляет клиентам, которые читают, оповещение о том, что файл изменен
* Выдает список файлов, доступных пользователю

## Фронтенд (GUI)
* Окно с информацией по доступным файлам. Их состоянию локально и на сервере
* Кнопки для "скачать", "отправить"
